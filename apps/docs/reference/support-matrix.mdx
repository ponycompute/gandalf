Gandalf runs on macOS (Apple silicon and Intel).

| Agent | Skills | Work handoff |
| --- | --- | --- |
| Claude Code | Yes | Yes |
| Codex | Yes | Yes |
| Cursor | Yes | No |

## Skill directories

| Agent | `--agent` value | User scope | Project scope |
| --- | --- | --- | --- |
| Claude Code | `claude-code` | `~/.claude/skills/` | `.claude/skills/` |
| Codex | `codex` | `~/.codex/skills/` | `.codex/skills/` |
| Cursor | `cursor` | `~/.cursor/skills/` | `.cursor/skills/` |

## What counts as a skill

A skill is a directory directly inside one of the directories above that contains a `SKILL.md` file. The directory name is the skill name.

- Directories without `SKILL.md` are ignored.
- Directories whose name starts with `.` are ignored, including agent-bundled skills such as `~/.codex/skills/.system`.
- Skills nested deeper than one level are not listed.
- Skills that an agent loads from elsewhere (plugins, marketplaces, `~/.agents/skills`) are not listed.

## How copies are compared

Two copies are the same when their files have identical paths and content. File permissions, timestamps, `.DS_Store`, and `.git` are not compared.

## Not managed

MCP servers, hooks, permissions, agent settings, and plugins are outside Gandalf's scope. The one exception is Gandalf's own handoff integration, which `gandalf init` registers in Claude Code and Codex.
