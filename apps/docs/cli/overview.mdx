Gandalf is a single Go binary that manages skills across Claude Code, Codex, and Cursor.

## Commands

| Command | Description |
| --- | --- |
| `gandalf` | List skills and how they line up across agents. Same as `gandalf skill list`. |
| [`gandalf skill list`](/cli/skill#list) | List skills and how they line up across agents. |
| [`gandalf skill show <name>`](/cli/skill#show) | Show where a skill is installed and print its `SKILL.md`. |
| [`gandalf skill add <path>`](/cli/skill#add) | Install a local skill directory into your agents. |
| [`gandalf skill sync [name...]`](/cli/skill#sync) | Copy skills to the agents that are missing them. |
| [`gandalf skill remove <name>`](/cli/skill#remove) | Remove a skill from your agents. |
| [`gandalf boost [profile]`](/cli/boost) | Switch the project's active skill profile from `gandalf.toml`. |

## Common flags

Available on `gandalf` and every `gandalf skill` command:

| Flag | Description | Default |
| --- | --- | --- |
| `--scope <scope>` | `user` or `project`. `list` also accepts `all`. | `user` |
| `--agent <agent>` | Limit to these agents: `claude-code`, `codex`, `cursor`. Repeat or comma-separate. | Agents with a config directory in your home |
| `--project`, `-p <dir>` | Project directory, used with `--scope project`. | `.` |
| `--home <dir>` | Home directory. | `$HOME` |
| `--json` | Emit JSON output. | Off |

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Invalid input, a failed operation, or a change Gandalf refused to make (a differing copy without `--from` or `--force`). |
