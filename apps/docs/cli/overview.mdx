Gandalf is a single binary with two groups of commands: skill management, which is stateless, and work handoff, which talks to a local background service.

## Skill commands

| Command | Description |
| --- | --- |
| `gandalf` | List skills and how they line up across agents. Same as `gandalf skill list`. |
| [`gandalf skill list`](/cli/skill#list) | List skills and how they line up across agents. |
| [`gandalf skill show <name>`](/cli/skill#show) | Show where a skill is installed and print its `SKILL.md`. |
| [`gandalf skill add <path>`](/cli/skill#add) | Install a local skill directory into your agents. |
| [`gandalf skill sync [name...]`](/cli/skill#sync) | Copy skills to the agents that are missing them. |
| [`gandalf skill remove <name>`](/cli/skill#remove) | Remove a skill from your agents. |

## Work handoff commands

| Command | Description |
| --- | --- |
| [`gandalf init`](/cli/handoff#set-up) | Connect Claude Code and Codex and install the background service. |
| [`gandalf status`, `gandalf doctor`](/cli/handoff#check-the-installation) | Check the service and the local installation. |
| [`gandalf daemon`](/cli/handoff#the-background-service) | Start, stop, or read the logs of the background service. |
| [`gandalf work`](/cli/handoff#work) | List and show tracked work in this project. |
| [`gandalf handoff <id>`](/cli/handoff#work) | Print the handoff contract for one piece of work. |
| [`gandalf search <query>`](/cli/handoff#work) | Search tracked work in this project. |
| [`gandalf evidence <id>`](/cli/handoff#evidence) | Show one piece of recorded evidence. |
| [`gandalf tui`](/cli/handoff#work) | Browse tracked work in a terminal UI. |
| [`gandalf mcp`](/cli/handoff#mcp-server) | Serve handoff context to an agent over MCP. |
| [`gandalf agent`](/cli/handoff#set-up) | List, connect, or disconnect agents. |
| [`gandalf config`](/cli/handoff#settings) | Show or change settings. |
| [`gandalf forget`](/cli/handoff#forgetting-data) | Delete recorded work or all data for this project. |

## Global flags

| Flag | Description | Default |
| --- | --- | --- |
| `--output <format>` | `text` or `json`. | `text` |
| `--project-root <dir>` | Project directory. | Current directory |

Gandalf uses `$HOME` to find agent directories and its own data.

## Skill flags

Available on every `gandalf skill` command:

| Flag | Description | Default |
| --- | --- | --- |
| `--scope <scope>` | `user` or `project`. `list` also accepts `all`. | `user` |
| `--agent <agent>` | Limit to these agents: `claude-code`, `codex`, `cursor`. Repeat or comma-separate. | Agents with a config directory in your home |

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | A skill command failed, or refused a change (a differing copy without `--from` or `--force`). |
| `2` | Invalid arguments. |
| `69` | A handoff command could not reach the background service or was given an invalid project or identifier. |
