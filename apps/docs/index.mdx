Gandalf is a local skill manager for Claude Code, Codex, and Cursor. Each agent keeps its skills in its own directory, so the same skill ends up installed in one agent, missing in another, and quietly edited in a third. Gandalf lines them up and fixes that.

## What Gandalf does

- **Lists skills across agents.** Run `gandalf` to see every skill and whether each agent has it.
- **Detects differing copies.** Skills are compared by content hash, so an edited copy shows up as `diverged` instead of passing as installed.
- **Syncs skills.** `gandalf skill sync` copies skills to the agents missing them. Copies that differ are only overwritten when you name the agent whose copy wins.
- **Adds and removes skills.** Install a local skill directory into every agent at once, or remove it everywhere.
- **Keeps what it displaces.** Replaced and removed skills move to `~/.gandalf/trash` instead of being deleted.

## What Gandalf does not do

- It does not manage MCP servers, hooks, permissions, or agent settings.
- It does not download skills from the network; `gandalf skill add` takes a local directory.
- It does not need a manifest, an account, or any configuration.

## Current support

Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`), and Cursor (`~/.cursor/skills`), plus the matching project directories. See the [support matrix](/reference/support-matrix).
