Gandalf ships as a single binary for macOS on Apple silicon and Intel. Linux and Windows are not supported yet: the work handoff service depends on the macOS keychain and launchd.

## Install script

```bash
curl -fsSL https://raw.githubusercontent.com/ponycompute/gandalf/main/install.sh | sh
gandalf --help
```

The script:

1. Finds the latest release on GitHub.
2. Downloads the archive for your architecture and verifies it against the release's `checksums.txt`.
3. Installs `gandalf` to `~/.local/bin`.

If `~/.local/bin` is not on your `PATH`, the script tells you to add it.

| Variable | Purpose | Default |
| --- | --- | --- |
| `GANDALF_INSTALL_DIR` | Directory to install into. | `~/.local/bin` |
| `GANDALF_INSTALL_TAG` | Install a specific release, such as `v0.10.0`. | Latest release |

To update, run the script again. To uninstall, delete the `gandalf` binary; `~/.gandalf` holds its data.

## Source build

Building needs the Rust toolchain pinned in `rust-toolchain.toml`; `rustup` installs it automatically.

```bash
git clone https://github.com/ponycompute/gandalf.git
cd gandalf
make build
./target/release/gandalf --help
```

## Prebuilt release binaries

Prebuilt macOS binaries are published on every `v*` tag on the [GitHub Releases page](https://github.com/ponycompute/gandalf/releases). Download the tarball for your architecture, extract, and place `gandalf` on your `PATH`.

## Verify the install

```bash
gandalf --help
gandalf
```

Running `gandalf` with no arguments is read-only. It lists the skills each agent has installed.
