## 1. Install

```bash
curl -fsSL https://raw.githubusercontent.com/ponycompute/gandalf/main/install.sh | sh
```

Options and source builds are on the [install page](/install).

## 2. See your skills

```bash
gandalf
```

```text
SKILL          CLAUDE CODE  CODEX    CURSOR  STATUS
code-review    yes          yes      yes     synced
pr-summary     yes          -        -       partial
team-reviewer  3f9a1c2      b81e07d  -       diverged

3 skills: 1 synced, 1 partial, 1 diverged
```

This is read-only. Each skill gets one status:

| Status | Meaning |
| --- | --- |
| `synced` | Every agent has identical content. |
| `partial` | The copies that exist are identical, but some agents lack the skill. |
| `diverged` | At least two agents hold different content. Cells show each copy's short hash. |

Only agents with a config directory in your home (`~/.claude`, `~/.codex`, `~/.cursor`) are shown. Pass `--agent` to choose explicitly.

## 3. Sync what is missing

Preview first, then apply:

```bash
gandalf skill sync --dry-run
gandalf skill sync
```

`partial` skills are copied to the agents missing them. `diverged` skills are left alone and the command exits with status 1 until you choose a winner.

## 4. Resolve a diverged skill

Compare the copies, then pick the agent whose copy wins:

```bash
gandalf skill show team-reviewer
gandalf skill sync team-reviewer --from claude-code
```

The overwritten copies move to `~/.gandalf/trash`.

## 5. Add or remove a skill everywhere

```bash
gandalf skill add ./my-skill
gandalf skill remove my-skill
```

## Project skills

Every command works on user skills by default. Add `--scope project` to work on the skills in the current repository (`.claude/skills`, `.codex/skills`, `.cursor/skills`), or `--scope all` on `list` to see both.
