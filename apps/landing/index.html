● One library, projected

Your skills live in one folder.
Every agent sees its own.

Each agent reads skills from its own dotfolder. gandalf keeps the real files in ~/.gandalf/skills and puts a link — or a clean copy, where links won't do — in every folder that should have it.

Adopt what you have

gandalf finds the skills already sitting in your agents' folders and moves them into the library in one step. Where copies differ, you pick the one to keep.

Install from anywhere

A local folder or any git URL, pinned to a commit. Updates move it forward only when you ask, and never over your own edits.

Choose per agent

Every skill is a row and every agent a column. Turn a skill on for Claude Code and off for Cursor with one checkbox.

✗ Safety

Your files shall not be overwritten.

Your agents' folders sit next to everything else you care about. gandalf works there by a few rules it does not bend.

  1. Plan first. Every change is listed before it happens. Apply works the plan out again, so what you saw is what runs — or nothing does.
  2. Hands off your work. A folder you made, a link you set up or a copy you edited is reported and left exactly as it is.
  3. Trash, not delete. Copies gandalf removes go to the Trash, where you can get them back.
  4. One at a time. A lock keeps the app and the CLI from writing at once.

? Questions

            
Good to know.

          

          

            

              Will gandalf touch skills I already placed?
              

                Not unless you ask. They show as ? Not managed.
                Adopt moves one into the library and links it back; until then gandalf only reads
                it.
              

            

            

              Link or copy — which does it use?
              

                By default gandalf checks whether a folder can hold a link and links when it can,
                copies when it can't. You can set link or copy per agent.
              

            

            

              What if I edit a skill by hand?
              

                Edit the library and every linked agent sees it right away. If you edited a git
                skill, gandalf stops updating it until you move your edits elsewhere — it never
                updates over your work.
              

            

            

              Where does my data go?
              

                Nowhere. The library is a folder of plain files on your disk. gandalf has no account
                and no server.
              

            

            

              Which agents are supported?
              

                Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot, OpenCode, Amp, Antigravity,
                Goose, Kilo Code, Roo Code, Grok and OMP Agent. You can point any of them at a
                different skills folder.
