# v0.11.0 Release Notes

Release title: `v0.11.0 - Skills Drafted From Your Own Sessions`

## Summary

v0.11.0 turns what you work out with your coding agent into skills. `gandalf distill` reads your recent Claude Code and Codex sessions and asks your own agent what a fresh agent would need to be told next time. `gandalf suggest` groups those lessons and drafts a skill for each area of work. `gandalf tui` reviews the drafts, and `gandalf skill test` measures whether a skill actually helps.

This release also fixes where Codex and Cursor skills are written: they now go to the directories those agents actually read.

## Changes to existing behavior

- **Codex and Cursor skills are written to `~/.agents/skills`.** v0.10.0 wrote them to `~/.codex/skills` and `~/.cursor/skills`, which Codex does not read as its user skill directory, so a skill reported as `synced` for Codex could be invisible to it. Each agent now has the list of directories it reads, in its own precedence order, and Gandalf writes to the first one. Codex and Cursor share `~/.agents/skills`, so one copy serves both. A legacy copy in `~/.codex/skills` is still listed for Codex but loses to the shared directory when both hold the same name. Run `gandalf skill sync --dry-run` to see what would move.
- **`gandalf tui` opens the skill draft inbox.** The work browser from v0.10.0 is now `gandalf tui --work`.
- **Errors are prefixed with `error:`** and print a hint with the next step. JSON output and exit codes are unchanged.

## Distill sessions into skills

Nothing is sent to Gandalf. Redacted excerpts of a session go only to the agent the session came from, run non-interactively on your own subscription.

- **`gandalf distill`** finds the Claude Code and Codex sessions for the current project, compresses each into a redacted trace (what you typed, every failure with its error and what followed, routine tool use collapsed into counts), and asks the agent for lessons. Claude Code sessions go to `claude -p`, Codex sessions to `codex exec`. `--since <days>`, `--limit <n>`, `--agent claude-code|codex`, `--dry-run`. Set `GANDALF_CODEX_MODEL` if your Codex account's default model refuses non-interactive use.
- **`gandalf suggest`** groups the stored lessons by area of work and decides whether each group is a skill, an always-on rule for `CLAUDE.md`/`AGENTS.md`, or noise. Each skill gets a drafted `SKILL.md` under `~/.gandalf/distill/<project>/drafts/`. The previous grouping is kept in `groups.json` so names stay stable between runs; `--fresh` starts over.
- **Provenance**: each draft carries a `provenance.json` with its session ids, lesson titles, and drafting date. A draft built from a single session gets a re-check date 30 days out. `gandalf skill show` says where a skill came from, and `gandalf skill list` warns when a re-check is due.

A typical run costs about $0.15 per distilled session and about $0.15 plus $0.05 per drafted skill for `suggest`, on your own subscription.

## Review and test drafts

- **`gandalf tui`** runs from local files, with no background service. The Inbox lists the project's drafts with their session and lesson counts and previews the `SKILL.md`. `a` installs the draft into the project for every detected agent and moves it to `approved/`; `x` moves it to `dismissed/`. The Skills panel shows what is installed and whether every agent has the same copy.
- **`gandalf skill test <path>`** writes realistic problems and rubrics from a `SKILL.md`, has Claude Code answer each one read-only in the repository with and without the skill, and grades both answers blind. The report shows rubric points, tool calls, time, and whether the skill was loaded, and is saved as `evaluation.json` beside the skill. `--problems <n>`, `--max-budget-usd <usd>` per answering run, `--dry-run`.

## Other changes

- `gandalf skill` output uses color when writing to a terminal and `NO_COLOR` is unset.
- Every subcommand, argument, and flag is described in `--help`, with examples in the root help.
- `gandalf doctor` prints each check with a mark, a plain description, and the fix, followed by a summary. Platform failures report their real cause instead of always suggesting `gandalf daemon start`.
- The work browser (`gandalf tui --work`) shows the selection, real status filter counts, scrolling, and key hints. Movement keys in the contract view scroll the contract instead of moving the hidden list selection, and `ctrl+c` quits.
- rustls is updated to 0.23.45, which fixes TLS 1.3 handshake messages being accepted across encryption level boundaries.
